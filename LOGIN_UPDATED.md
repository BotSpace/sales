# ✅ LOGIN FORMA YANGILANDI!

## 📋 O'zgarishlar

Login forma endi **telefon + parol** ko'rinishida.

### Yangi Forma:

```
┌──────────────────────────────┐
│  Xush Kelibsiz               │
│  Davom etish uchun kiring    │
├──────────────────────────────┤
│  Telefon Raqami              │
│  +998 [ _ _ _ _ _ _ _ _ _ ]  │
├──────────────────────────────┤
│  Parol                       │
│  [ ********** ] 👁️          │
├──────────────────────────────┤
│  [ Kirish ]                  │
└──────────────────────────────┘
```

## ✨ Xususiyatlar

1. **Telefon Input**
   - +998 avtomatik prefix
   - 9 ta raqam
   - Faqat raqamlar

2. **Parol Input**
   - Password type (yashirin)
   - Show/Hide tugmasi (ko'z)
   - Har qanday uzunlik

3. **Submit Tugma**
   - Disabled: telefon < 9 yoki parol bo'sh
   - Loading state: "Kirilmoqda..."
